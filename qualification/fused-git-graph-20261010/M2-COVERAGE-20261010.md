## Canonical stream — REQ-DET-0001

`examples/canonical_workload.rs` writes **raw ASCII** byte stream with literal LF line ends and header `PF-CANONICAL-POLYNOMIAL-V1`. Each record `operation-id|Z|coefficient-count|comma-separated-signed-base10-integers` or `operation-id|Q|coefficient-count|comma-separated-signed-base10-numerator/positive-base10-denominator`, canonical ascending degree, zero `count=0`, or `operation-id|ERR|stable-error-variant`. Signs, numerator/denominator, trailing-zero stripping, IDs and list ordering are explicit; it does not use Debug formatting, platform Hash, time, OS paths, random hash seeds, or locale.

The seeded dense generator is defined by unsigned 64-bit wrapping LCG with `seed=20261010 XOR salt`, `seed=seed*6364136223846793005+1442695040888963407 mod 2^64`, coefficient `(seed>>33)%41-20`. The oracle independently reproduces it.
