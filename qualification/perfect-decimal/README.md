The public-API-only Rust tests independently implement exact arithmetic over bounded
primitive integers, validate precise Integer/Rational contracts, check numerical
Eq/Ord/Hash and quantum/signed-zero rules, and exercise explicit rounding and
resource boundaries. The 440 retained rounding vectors are regenerated and
verified with Python's *stdlib decimal* module by
`scripts/verify_oracle.py`; they are not generated by Perfect Decimal or
Perfectπ.

`scripts/materialize_private.py` verifies exact pinned dependency declarations
before converting them to paths within an **isolated** job checkout. These paths
must contain exactly the pinned Git sources. This is private-Git CI materialization
only, **not** evidence that a published-registry consumer builds.

The callable `.github/workflows/perfect-decimal.yml` binds both the candidate
and qualification harness revisions explicitly. It defines Q0–Q5 checks on three
Class-A hosts and Class-B `no_std + alloc` checks. Merely configuring a workflow
does not prove that its runner executed successfully.

## Gate ledger

- Q0: Exact source, dependency inventory, MSRV and source-boundary checks pending hosted execution.
- Q1: MSRV, feature, three-host and Class-B matrices pending hosted execution.
- Q2: Independent public Decimal/Numeric/Arithmetic/Rational consumer tests.
- Q3: Determinism and canonical representation coverage present; cross-host fingerprint qualification pending.
- Q4: Consumer boundary tests supplement the separately retained Decimal mutation/fuzz/Miri evidence; **17 full-suite timeouts unresolved in the earlier source report** and must be reconciled against focused tests.
- Q5: Independent primitive integer and Python decimal checks locally executable.
- Q6: **not claimed**; native ARM64, full hardening acceptance, release gate, registry packaging and historical-reuse completion are independent requirements.

The authoritative M1 lifecycle remains in Perfect Decimal `project-status.toml`.
Never treat this fixture as a runtime dependency of the Decimal crate.
