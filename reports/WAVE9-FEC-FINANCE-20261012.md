## Implementation acceptance considerations

Public Hamming packed APIs explicitly take bit order and bit count,
refuse nonzero padding and malformed length, and preserve original
logical bit-position reporting. Independent test consumers verify
encoding and decoding against externally generated bytes, including
partial bytes, and both SEC and SECDED modes. Independent negative
profile checks distinguish field parents, lengths, evaluation
conventions and supported code parameters; no wire-standard compliance
is asserted.

The production Reed–Solomon Berlekamp–Welch solver retains its
n<=16 limit and MDS correction bound, unchanged `max_trials` semantics,
and the exhaustive test-only differential oracle. One inversion per
pivot and reused evaluation powers are bounded O(n²) scratch changes,
not an asymptotic bound increase; peak heap consumption has not been
instrumented.

Finance `net_cash_flows_by_currency` reuses the exact bounded
coarse-to-fine grouping kernel and returns one deterministic total per
present currency, without FX, rounding or implicit quantum. Independent
Decimal reference rows cover multi-date, signed values and zero
quantum; production regressions also exercise 100000-power cancellation,
input limits and reversed-order invariance.
